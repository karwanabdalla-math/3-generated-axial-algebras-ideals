# GAP Computations for 3-Generated Axial Algebras of Jordan Type 1/2

This repository contains GAP scripts supporting research on the ideal structure of universal 3-generated primitive axial algebras of Jordan type 1/2.

## Mathematical setting

Let \(A=A(\alpha,\beta,\gamma,\psi)\) be the universal 9-dimensional primitive axial algebra of Jordan type \(1/2\), generated by three axes \(a,b,c\) over a field of characteristic different from 2.

The computations concern multiplication operators, structural identities, invariant subspaces, submodules, and ideals of \(A\).

## Computational software

The calculations are performed using GAP (Groups, Algorithms, Programming).

Official website: https://www.gap-system.org/

## Available scripts

### `check_permutation_symmetry.g`

Symbolically verifies the compatibility of the universal multiplication table with permutations of the three generating axes.

The script is intended to establish the relevant identities independently of particular numerical parameter values.

## Running the scripts

Download the repository and execute the GAP script using:

```bash
gap check_permutation_symmetry.g
```

The scripts should be checked against their stated expected outputs.

## Reproducibility

The purpose of this repository is to make the computational verification underlying the mathematical results accessible to readers and referees.

Additional GAP scripts will be added as the verification of the results is completed.
